# Contribuer · Contributing

## Français

Merci de vouloir contribuer ! Le code ouvert du Gnome Archiviste vit dans deux organisations, chacune avec son guide
de contribution, son code de conduite et sa politique de sécurité :

- **PHIL** (*Parler Haut, Interagir Librement*) — la plateforme et ses paquets `phil/*`, le système de design PHIL UX :
  [guide de contribution](https://github.com/parler-haut-interagir-librement/.github/blob/main/CONTRIBUTING.md).
- **Tilttek** — les paquets de jeu et de ludification `tilttek/*` :
  [guide de contribution](https://github.com/TiltTek/.github/blob/main/CONTRIBUTING.md).

Pour les fiches de personnage de cette organisation, ouvrez un ticket dans le dépôt concerné. Pour une question sur
la boutique ou une commande, écrivez-nous plutôt par [gnomearchiviste.ca](https://gnomearchiviste.ca).

## English

Thank you for wanting to contribute! Le Gnome Archiviste's open source lives in two organisations, each with its own
contributing guide, code of conduct and security policy:

- **PHIL** (*Proclaim Honestly, Interact Liberally*) — the platform and its `phil/*` packages, and the PHIL UX design
  system: [contributing guide](https://github.com/parler-haut-interagir-librement/.github/blob/main/CONTRIBUTING.md).
- **Tilttek** — the `tilttek/*` game and gamification packages:
  [contributing guide](https://github.com/TiltTek/.github/blob/main/CONTRIBUTING.md).

For the character sheets in this organisation, open an issue in the repository concerned. For a question about the
shop or an order, please reach us through [gnomearchiviste.ca](https://gnomearchiviste.ca) instead.
